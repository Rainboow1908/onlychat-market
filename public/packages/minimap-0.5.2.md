# 小地图

在游戏界面角落显示当前所在层的地形、附近玩家和生物。地图按方块绘制，可以缩放、旋转，也能直接右键传送。

## 打开与调整

- 启用插件后，小地图默认出现在右上角；关闭插件即隐藏。
- 按住地图拖动可以移动位置，拖边缘可以改大小。
- 所有设置都在 `设置 → 插件 → 已安装 → 小地图`。

## 设置

### 小地图

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 显示位置 | 右上 | 右上 / 左上 / 右下 / 左下 |
| 尺寸 | 220 px | 160–320 |
| 不透明度 | 0.92 | 0.5–1 |
| 形状 | 圆角 | 方形 / 圆角 / 圆形 |
| 地图缩放 | 0.9 | 0.5–2.5；鼠标滚轮也在这个范围内连续缩放 |
| 朝向 | 北向上 | 北向上 / 跟随玩家 |

### 显示

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 方块材质细节 | 1 | 1 = 方块平均色；2–16 = 使用方块上方面材质，缩得很小时仍保留材质取样 |
| 常加载整张地图 | 开 | 缩小或旋转时边缘仍是真实地形；关闭后只保留可视范围 |
| 方块描边 | 关 | 打开后每个方块加 1px 深色边；默认关闭时格子之间没有缝隙 |
| 主题 | 深色 | 深色 / 高对比 / 浅色 |
| 地形起伏阴影 | 开 | 按地面高度增加明暗 |
| 显示网格 | 关 | 每 16 格一条参考线 |
| 显示坐标 | 开 | 显示自己所在坐标 |
| 显示当前层 | 开 | 显示当前 Y 层 |
| 显示东南西北 | 开 | 在地图边缘显示 N / E / S / W |

### 玩家

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 显示玩家 | 开 | 显示其他玩家 |
| 显示自己 | 开 | 在地图中心显示自己 |
| 玩家名称 | 悬浮显示 | 始终显示 / 悬浮显示 / 关闭 |
| 悬浮查看名称和坐标 | 开 | 鼠标停在头像上显示信息 |

### 实体

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 显示实体 | 开 | 实体显示的总开关 |
| 敌对生物 | 开 | 僵尸、骷髅等 |
| 被动生物 | 开 | 动物、村民等 |
| 掉落物 | 关 | 地上的物品 |
| 弹射物 | 关 | 箭、雪球等 |
| 其他实体 | 关 | 未归类的实体 |
| 实体垂直范围 | 8 格 | 4–32；只显示与自己高度接近的目标 |

### 性能

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 采样范围 | 128 格 | 32–256；调大可看到更远的地形，也更吃性能 |
| 刷新率 | 2 Hz | 1–4；越高越跟手，也越吃性能 |

## 地图上的信息

- 地图中心固定为自己，缩放和旋转不会让中心漂移。
- 站在露天时，地图显示真实地表和周围高地，不会因为自己位置低就切掉旁边的山。
- 进入屋顶、洞穴或树下时，地图保持当前 Y 层，不会透出墙后的地形。
- 其他玩家用固定 16px 的皮肤头像表示，位置按连续世界坐标绘制，不吸附到方块中心；找不到皮肤时显示首字母圆形。
- 玩家和生物只显示与自己在同一高度层附近的目标。

## 右键传送

- 右键玩家头像：传送到该玩家，发送 `/tp 玩家名`。
- 右键地图空白处：传送到该位置，发送 `/tp x y z`，高度取地图里的地形高度。
- 弹出菜单会显示目标名称和坐标；服务器必须允许你使用 `/tp`，否则命令不会生效。

## 资源与缓存

- 第一次启用时会准备 Minecraft 方块贴图；本机已有对应版本的客户端文件时直接读取，导入后删除临时文件。
- 贴图和平均色缓存在 `.data/plugins/minimap/resources/`，之后启动不会重复下载。
- 只读取方块贴图和当前游戏数据，不读取聊天记录。

## 性能建议

- 卡顿时先调小“采样范围”，再降低“刷新率”。
- 不需要更远视野时可以关闭“常加载整张地图”；关闭后缩小地图时边缘可能只显示平均色。
- 关闭不常看的实体类别、降低“方块材质细节”，都能减少绘制量。
- “方块描边”默认关闭；打开会增加一点绘制开销。

## 隐私

- 只读取当前连接服务器的地形、玩家列表和实体位置。
- 方块贴图从 Mojang 下载，不会上传你的坐标、聊天或账号信息。
- 缓存只保存在本机的插件数据目录。

## 常见问题

**地图一片空白？** 确认已经连接服务器、插件已启用；刚进入服务器时区块还没加载完，稍等即可。第一次启用还要等贴图准备完成。

**地形只有色块？** “方块材质细节”为 1 时就是平均色，调到 2–16 可以显示方块材质。

**玩家头像移动有点跳、看起来偏大？** 头像是固定 16px，默认每秒只采样 2 次，所以移动会有轻微阶梯感；这不是坐标偏移。把“刷新率”调到 3–4 Hz 会更跟手。

**在洞穴里看不到地表？** 这是有意为之：有屋顶时不透出墙后的地形，避免暴露洞穴结构。

**缩到最小后边缘是纯色？** “常加载整张地图”开启时边缘仍是真实地形；关闭后可视范围外没有数据，会显示边缘平均色。

**右键没有反应？** 需要点在玩家头像或地图空白处；服务器不允许 `/tp` 时命令不会执行。

**换了服务器地图没更新？** 地图跟随当前会话，切换服务器后需要几秒重新采样。
